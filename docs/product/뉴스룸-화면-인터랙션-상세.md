> 상위 문서: `뉴스룸-uiux-가이드.md` (파이프라인·API 계약·원칙) / `안심-product-thesis.md` (제품 철학)
> 이 문서는 **화면 배치와 사용자 인터랙션**만 다룬다. 데이터가 어떻게 만들어지는지는 상위 문서 참조.

## 0. 화면 지도

```
[뉴스룸 리스트]  ←― 탭 진입점 (유한한 브리핑 페이지)
   │
   ├─ 종목 다이제스트 카드 탭 ──→ [다이제스트 상세] ──→ [근거 기사 (인앱 브라우저)]
   │                                    └──→ (번역 인라인 확장 — 화면 이동 없음)
   ├─ 시장 스토리 카드 탭 ────→ [시장 스토리 상세] (다이제스트 상세와 동일 템플릿)
   └─ 학습 카드 탭 ──────────→ [학습 카드 상세 시트]
```

내비게이션 규칙: 상세는 push(`navigationDestination(item:)`), 번역·학습은 sheet. 뎁스 2를 넘기지 않는다.

## 1. 리스트 화면 (탭 진입 시)

### 1.1 전체 배치 — calm 상태 기준

```
┌─────────────────────────────────────┐
│ 뉴스룸                               │  ← 타이틀
│ 7월 12일 06:00 기준 · 다음 업데이트는  │  ← 기준 시각 라인 (항상 노출)
│ 내일 아침이에요                       │
├─────────────────────────────────────┤
│ ◦ 오늘의 브리핑                       │  ← 상태 브리핑 카드 (§1.2)
│   "시장은 조용한 하루였어요. 보유       │
│    종목 중 2개에 새로운 소식이 있어요"  │
├─────────────────────────────────────┤
│ 시장 전체                             │
│ ┌─────────────────────────────────┐ │
│ │ [시장 스토리 카드]                 │ │  ← 없으면 섹션 자체 숨김 (§1.3)
│ └─────────────────────────────────┘ │
├─────────────────────────────────────┤
│ 내 종목                              │
│ ┌─────────────────────────────────┐ │
│ │ ★ 히어로 카드 (materiality high)  │ │  ← §1.4-A
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ 컴팩트 로우 (materiality low)     │ │  ← §1.4-B
│ ├─────────────────────────────────┤ │
│ │ 조용 로우 (hasNews=false)        │ │  ← §1.4-C
│ └─────────────────────────────────┘ │
├─────────────────────────────────────┤
│ 이걸 이해하려면                       │
│ ┌──────────┐ ┌──────────┐           │  ← 학습 카드 가로 스크롤 (§1.5)
│ │ 학습카드  │ │ 학습카드  │           │
│ └──────────┘ └──────────┘           │
├─────────────────────────────────────┤
│      ── 오늘 브리핑은 여기까지예요 ──   │  ← 종료 마커 (§1.6)
│      52일째 큰 변동 없이 지나가는 중    │
└─────────────────────────────────────┘
```

- 컨테이너: `PFContentScrollView(spacing: 20, scrollsToTopOnAppear: true, locksHorizontalOverflow: true)` + `.policyFinanceLightTabChrome()` — 기존 관례 유지.
- **무한 스크롤·페이지네이션 없음.** 콘텐츠는 항상 유한하고, 끝이 보인다.
- 철거: 시세 티커 헤더(`NewsroomHeaderView`), "실시간 속보" 필터, 뉴스/콘텐츠 피드 모드 피커. 학습 콘텐츠는 별도 모드가 아니라 리스트 하단 섹션으로 흡수된다.

### 1.2 상태 브리핑 카드

리스트 최상단. 앱 전체 severity(단일 소스, 오늘탭 `TodayBriefingSeverity`와 동일 값)를 읽는다.

| severity | 액센트 | 내용 | 톤 |
|---|---|---|---|
| calm | 없음 | 오늘 요약 1~2문장 + 새 소식 있는 종목 수 | "조용해요"가 핵심 정보 |
| watch | `Color.warning` 좌측 4px | 무엇을 지켜보는 중인지 1문장 + (조건 충족 시) caution 문구 | 차분한 주시 |
| alert | `Color.trendDown` 좌측 4px | "오늘 무슨 일이 있었나" 요약 + 과거 base rate 1줄 | 설명, 공포 증폭 금지 |

- caution 문구 노출 5조건(수치 비노출·등급 게이트·침묵 비대칭·base rate 페어링·단일 소스)은 상위 문서 §5.5를 따른다. v1은 실현 변동성 트리거.
- 탭 인터랙션: alert/watch일 때만 탭 가능 → 시장 스토리 상세로 연결. calm일 땐 정적(탭 없음 — 눌러볼 것을 유도하지 않는다).

### 1.3 시장 공통 스토리 카드

- 매크로 버킷 발행물이 있을 때만 렌더. 없으면 헤더 포함 섹션 전체 숨김 (빈 상태 카드 만들지 않음).
- 구성: 우산 제목 · 요약 1문장 · "지금까지의 줄거리 보기" 텍스트 버튼(storyline 있을 때) · 갱신 시각.
- 탭 → 상세 (다이제스트 상세와 동일 템플릿, 단 ①자산 영향 블록은 "내 자산 전체" 기준으로 표시).

### 1.4 종목 다이제스트 카드 — 3가지 변형

정렬 순서: materiality high → low → 조용. 같은 그룹 안에서는 보유 비중 순.

**A. 히어로 카드 (`hasNews && materiality == high`)**
```
┌─────────────────────────────────────┐
│ NVDA · 내 자산의 12%                  │
│ 엔비디아, 차세대 칩 출하 일정 발표      │  ← 우산 제목 (크게, 2줄 제한)
│ 오늘 -2.1% · 내 총자산 기준 -0.25%     │  ← 자산 영향 미리보기 1줄
│ 새로 확인된 사실 2건 · 근거 기사 5건    │
└─────────────────────────────────────┘
```

**B. 컴팩트 로우 (`hasNews && materiality == low`)**
```
│ AAPL   공급망 관련 보도 1건            ›│   ← 제목 1줄 + 셰브런
```

**C. 조용 로우 (`hasNews == false`)**
```
│ MSFT   3일째 특이사항 없음 · 지켜보고 있어요 │
```
- **탭 불가.** 상세로 갈 내용이 없다. 눌리는 척하지 않도록 셰브런·하이라이트 없음.
- 회색 처리/비활성 스타일 금지 — 조용함은 긍정 정보다. 본문 텍스트는 `textPrimary` 유지, 보조 문구만 secondary.
- quietDays는 서버 값 그대로 표기.

- A/B 탭 → 다이제스트 상세 push. 눌림 피드백은 기존 카드 관례(스케일/하이라이트) 따름.
- 카드에 컨텍스트 메뉴·스와이프 액션 없음 (저장 기능은 v1 범위 제외 — 기존 `toggleSaved`는 이 화면에서 재사용하지 않는다).

### 1.5 학습 카드 섹션 — "이걸 이해하려면"

- **콘텐츠는 인하우스 evergreen 개념 카드** (30~50장 라이브러리, LLM 초안 + 사람 검수 1회). 외부 애널리스트 해석·등급·목표가 데이터는 사용 금지 — 매매 의견 반입 경로가 된다.
- 노출 로직: 오늘 다이제스트들의 개념 태그와 매칭되는 카드 최대 3장 (예: 금리 뉴스가 있으면 "금리와 성장주" 카드). 매칭 없으면 라이브러리에서 미노출 오래된 순 2장.
- 레이아웃: 가로 스크롤 카드 (제목 + 읽는 시간 "2분" + 개념 아이콘). 기존 `NewsroomLearningContent` 모델 재사용 가능.
- 탭 → 학습 상세 **시트** (push 아님 — 브리핑 흐름에서 이탈하지 않도록). 시트 안: 본문 + "관련된 오늘 소식" 역링크 1개.
- 초기 라이브러리 10장: 금리와 성장주 / 변동성과 VIX / 드로다운의 역사적 빈도 / 실적 시즌 읽는 법 / CPI·고용지표 / 장단기 금리차 / 집중도 리스크 / 패닉 셀의 역사적 비용 / 배당과 총수익 / 환율과 해외주식.

### 1.6 종료 마커

- "오늘 브리핑은 여기까지예요" + heartbeat 한 줄 (예: "52일째 큰 변동 없이 지나가는 중" — 오늘탭 기록 데이터 재사용).
- 이 아래에 어떤 콘텐츠도 두지 않는다. "더 보기", 추천, 무한 로딩 금지.

## 2. 상태별 리스트 변형 요약

| 요소 | calm | watch | alert |
|---|---|---|---|
| 브리핑 카드 | 정적, 탭 불가 | 액센트 + 탭 → 상세 | 액센트 + "오늘 무슨 일" + base rate, 탭 → 상세 |
| caution 문구 | 없음 (침묵 = 부재) | 조건 충족 시 브리핑 내 1줄 | 조건 충족 시 브리핑 내 1줄 |
| 시장 스토리 | 있을 때만 | 대체로 있음 | 최상단 고정, 히어로 크기 |
| 정렬 | 기본 | 기본 | 변동 큰 종목 우선 |
| 종료 마커 | heartbeat 문구 | 동일 | "이런 날일수록 천천히 보세요" 톤 |

alert 날에도 레이아웃 구조는 동일하다. 빨간 배너·전면 경고 화면 금지 — 구조가 그대로라는 것 자체가 안심 신호다.

## 3. 다이제스트 상세 화면

하나의 짧은 기사처럼 위에서 아래로 자연스럽게 읽힌다. 섹션 라벨·질문 헤더 없음 — 블록의 순서와 시각 위계만으로 흐름을 만든다. (내부 설계 논리는 "나 괜찮아 → 무슨 일 → 무슨 뜻 → 근거" 순서지만, 이 질문들은 화면에 노출하지 않는다.)

push로 진입, 내비게이션 타이틀은 비움 (스크롤 시 종목명 표시).

```
┌─────────────────────────────────────┐
│ ←                                   │
│                                     │
│ NVDA 엔비디아                        │  ← 종목 헤더
│ 오늘 -2.1%                           │  ← 큰 숫자 (사실)
│ 내 자산의 12% · 총자산 기준 -0.25%     │  ← 개인화 환산, 작은 보조 텍스트
│ ─────────────────────────────────── │
│                                     │
│ 엔비디아, 차세대 칩 출하 일정 발표      │  ← 우산 제목 (헤드라인 타이포)
│                                     │
│ 요약 본문 2~3문장이 리드 문단처럼       │  ← LLM 요약, 제목에 바로 이어짐
│ 자연스럽게 이어진다…                   │
│                                     │
│ 새로 알려진 내용                       │  ← 소제목 (질문형 아님)
│ • fact 1                            │
│ • fact 2                            │
│                                     │
│ ┌ 이게 무슨 뜻인가요? ──────────────┐ │  ← 본문 끝 인라인 버튼
│ └───────────────────────────────── ┘ │
│   (탭 → 같은 자리에서 번역 텍스트가     │
│    아래로 펼쳐짐. 화면 이동 없음)       │
│                                     │
│ 함께 보면 좋아요                       │  ← 매칭되는 학습 카드 있을 때만 1장
│ │ 📎 금리와 성장주 · 2분             ›│
│                                     │
│ 근거 기사 5                          │
│ │ 제목 · 출처 · 3시간 전             ›│  ← 탭 → 인앱 브라우저
│ │ …                                ›│
│                                     │
│ 7월 12일 06:00 기준 · AI가 여러 기사를  │  ← 푸터 자백 (항상)
│ 요약했어요. 원문과 다를 수 있어요        │
└─────────────────────────────────────┘
```

읽기 흐름 설계 의도:

1. **종목 헤더 = 주식앱의 익숙한 문법.** 종목명 + 오늘 등락이 먼저 오는 건 사용자가 이미 아는 패턴이라 라벨 없이도 "내 상황"으로 읽힌다. 개인화 환산("내 자산의 12% · 총자산 기준 -0.25%")은 등락 숫자 바로 아래 보조 텍스트로 — 이 한 줄이 이 화면의 차별점이므로 생략 금지.
2. **제목 → 본문이 기사처럼 이어진다.** 사이에 카드 경계·라벨을 두지 않는다. "새로 알려진 내용"만 유일한 소제목.
3. **번역은 인라인 확장.** 시트를 띄우지 않고 버튼 자리에서 아래로 펼쳐진다 — 읽기 흐름이 세로로 끊기지 않는 게 목적. 접기 가능. 로딩 중엔 버튼 자리에서 스켈레톤 2줄. (기존 `NewsroomInsightMode` 시트 패턴 대신 이 화면은 인라인. 캐싱은 동일하게 `ThemeSignalNarrativeCache` 패턴, 당일 만료.)
4. **학습 카드 역링크는 본문과 근거 사이 1장만.** 개념 태그 매칭 없으면 섹션 생략.

블록별 규칙:

- **종목 헤더**: 숫자와 사실만. 색상은 오늘탭 규칙 재사용 (calm 시 부호 기반, watch/alert 시 severity 색 고정 — `TodayModels.drawdownColor` 관례). 시장 스토리 상세에서는 이 블록을 "내 자산 전체 오늘 ±%" 기준으로 대체.
- **제목·요약**: 가드레일(상위 문서 §3.2) 적용된 발행물 그대로. 클라이언트 재가공 금지.
- **번역 내용**: 사실의 해석 + 내 자산과의 연결까지. 전망·권유 문장 금지 (프롬프트 가드레일은 백엔드 책임).
- **근거 기사**: 인앱 브라우저(SFSafariViewController). 복귀 시 스크롤 위치·번역 펼침 상태 유지.
- caution 문구는 이 화면에 중복 표시하지 않는다 — 리스트 브리핑 카드 전용.

## 4. 인터랙션 명세

### 4.1 Pull-to-refresh
```
당김 → GET (ETag 포함)
  ├─ 304 → 햅틱 없이 "이미 최신이에요" 1.5초 토스트 → 종료
  └─ 200 → 콘텐츠 교체 + 기준 시각 라인 갱신
```
- LLM 생성을 트리거하지 않는다. 스피너 문구는 "확인하는 중…" (기다림을 약속하는 "불러오는 중" 금지 — 대개 즉시 304다).
- 하루 1회 갱신이 정상임을 UI가 반복 학습시킨다: 기준 시각 라인 + "이미 최신이에요"의 조합.

### 4.2 탭 재진입
- 탭 바 재탭 시 최상단 스크롤 (`scrollsToTopOnAppear` 관례 유지).
- 배지·붉은 점 금지. 새 다이제스트가 있어도 탭 아이콘은 변하지 않는다 (재방문 유도 장치 금지).

### 4.3 오늘탭에서의 진입
- 오늘탭 하단 뉴스 섹션 "더보기" → `onNewsroomTabRequested()` (기존 연결 유지). 진입 후 최상단부터 — 특정 카드로 앵커 점프하지 않는다.

### 4.4 로딩 / 에러 / 첫 진입
| 상황 | 처리 |
|---|---|
| 최초 로드 | 섹션 구조를 유지한 스켈레톤 (오늘탭 `TodaySkeletonViews` 관례) |
| 로드 실패 | 기존 `NewsroomErrorCard` + 재시도 버튼. 캐시가 있으면 캐시 표시 + 상단에 "○일 ○시 기준 (오프라인)" |
| 보유 종목 0 | "종목을 등록하면 관련 소식을 모아드려요" + 자산 등록 유도 1버튼 |
| 발행물 자체가 없음 (신규 유저 당일) | 시장 스토리 + 학습 카드만으로 구성, 종료 마커 유지 |

주의: `NewsroomEmptyCard`(불러올 데이터 없음)와 조용 로우(§1.4-C, 불러왔더니 평온)는 다른 컴포넌트다. 혼용 금지.

### 4.5 애니메이션·햅틱
- 콘텐츠 등장은 기본 페이드 수준. 카운트업, 펄스, 흔들림 등 주목 유도 모션 금지.
- 햅틱은 pull-to-refresh 성공(새 콘텐츠 있을 때)에만 가볍게. alert 상태 진입에 햅틱 금지 — 공포 증폭 장치가 된다.

## 6. 카피 톤 체크 (이 화면 전용 요약)

- 모든 화면에 기준 시각 자백. AI 생성물에는 "AI가 요약했어요" 푸터.
